# SmsTest Orders App

Консольное приложение для получения списка блюд и оформления заказов на его основании.

## Требования

* `NET 8.0` (тестировалось на `8.0.425`, см. `global.json` в корне решения для изменения списка поддерживаемых версий).

## Сборка

Все команды выполняются из каталога `SmsTest.OrdersApi.Console`.

Поддерживаются два вида клиентов: gRPC и REST. Переключением между ними реализовано через конфигурации и флаги
компиляции.

### gRPC-клиент:

```
dotnet build -c GrpcApp
```

Для упрощения отладки в каталоге `SmsTest.Mocks.OrdersApi.Grpc` имеется Mock-сервер gRPC. Его сборка аналогична:

```
dotnet build -c GrpcApp
```

Запускать можно параллельно (сперва сервер, потом клиент). Для Rider в репозитории лежат конфигурации параллельного
запуска (`Multi-Launch: SmsTest (gRPC)`, не забудьте переключить конфигурацию в `GrpcApp`).

### REST-клиент:

```
dotnet build -c RestApp
```

Для упрощения отладки в каталоге `SmsTest.Mocks.OrdersApi.Rest` имеется Mock-сервер REST. Его сборка аналогична:

```
dotnet build -c RestApp
```

Запускать можно параллельно (сперва сервер, потом клиент). Для Rider в репозитории лежат конфигурации параллельного
запуска (`Multi-Launch: SmsTest (REST)`, не забудьте переключить конфигурацию в `RestApp`).

## Работа с БД

Добавление новой миграции (выполнять из каталога `SmsTest.OrdersApi.Console`):

```
dotnet ef migrations add НазваниеМиграции --output-dir Data/Migrations
```

Применение миграции:

```
dotnet ef database update 
```

При запуске приложения БД автоматически создаёт и инициализируется начальной схемой, поэтому последняя команда не
является обязательной.

## Конфигурация

В файле `appsettings.json` можно настроить параметры подключения к серверу, строку подключения и параметры логирования:

* `Api:Rest` - настройки REST-сервера (при использовании Mock-сервера, убедитесь, что в его файле `appsettings.json`
  указан аналогичный порт).
* `Api:Grpc` - настройки gRPC-сервера (при использовании Mock-сервера, убедитесь, что в его файле `appsettings.json`
  указан аналогичный порт).
* `ConnectionStrings` - параметры строки подключения к серверу БД
* `Serilog` - параметры логирования (сейчас лог пишется рядом с приложением, файл создаётся с интервалом в один день,
  при достижении лимита в 1 МБ происходит разбиение на сегменты, всего 10 сегментов, с удалением старых сегментов при
  превышении общего числа сегментов).
