# Мок-сервер REST

Эмулирует поведение целевого сервера REST.

## Конфигурация

В файле `appsettings.json` можно настроить параметры подключения к серверу:

* `Auth:Username`, `Auth:Password` - имя пользователя и пароль, используемые при проверке Basic Auth.
* `Server:Port` - порт подключения к серверу (должен соответствовать порту, указанному на клиенте).

## Отладка

При запуске сервер сообщает адрес основного эндпойнта и адрес админ-панели для диагностики запросов. Последнюю можно
использовать для получения сведений о запросах, полученных от клиента, и причинах их приёма/отбраковывания.
