# SmsTest Variables App

Десктопное приложение для работы с указанным набором переменных среды.

## Требования

* `NET 8.0` (тестировалось на `8.0.425`, см. `global.json` в корне решения для изменения списка поддерживаемых версий).

## Сборка

Все команды выполняются из каталога `SmsTest.VariablesApp`.

```
dotnet build -c Release
```

## Конфигурация

В файле `appsettings.json` можно задать список имён переменных окружения, путь к каталогу персистентных данных и
параметры логирования:

* `Variables:Names` - фиксированный список имён переменных окружения, с которыми будет работать приложение.
* `Variables:CommentsPath` - путь к каталогу, содержащему персистентные данные комментариев для переменных окружения.
* `Serilog` - параметры логирования (сейчас лог пишется рядом с приложением, файл создаётся с интервалом в один день,
  при достижении лимита в 1 МБ происходит разбиение на сегменты, всего 10 сегментов, с удалением старых сегментов при
  превышении общего числа сегментов).
